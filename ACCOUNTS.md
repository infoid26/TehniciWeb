# Conturi și progres

Cursul poate fi folosit fără autentificare, cu progres salvat în browser. Conectarea cu Microsoft este disponibilă pentru conturile universitare `@s.unibuc.ro` și `@unibuc.ro` și permite sincronizarea progresului între dispozitive.

La prima conectare, progresul din browser este preluat în cont. Modificările făcute fără conexiune se păstrează și se sincronizează după reconectare. Conflictele între modificări păstrează ambele variante pentru alegerea utilizatorului.

Logout deconectează utilizatorul de pe platformă, fără a închide sesiunile altor servicii Microsoft.

Istoricul examenului este separat de progresul cursului. Biletele sunt marcate ca parcurse după predarea tuturor probelor, inclusiv bonusul. Abandonarea nu consumă bilete. După parcurgerea tuturor biletelor unei probe, setul acesteia se reia automat.

Platforma nu solicită parola universitară și nu salvează parole sau tokenuri Microsoft în progres.
