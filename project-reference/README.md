# Cofetăria Dulcelind

Proiect demonstrativ pentru HTML, CSS, JavaScript, Sass, Node.js, Express, EJS și PostgreSQL.

**[Deschide proiectul](https://tw.infoid26.ro/project/)**

Include pagini de prezentare, catalog de produse, filtrare, sortare, galerie responsive și preferințe păstrate în browser. Catalogul și paginile produselor folosesc PostgreSQL.

Legăturile de înregistrare și contact nu oferă formulare funcționale. Fonturile, pictogramele și videoclipurile externe necesită conexiune la internet.
