# Găzduire

Platforma folosește Node.js pe Azure App Service. Autentificarea Microsoft și sincronizarea progresului necesită serviciul de autentificare al platformei și PostgreSQL.

Exercițiile SQL, SCSS și EJS sunt evaluate în browser. Exercițiile Node.js și Express folosesc un serviciu separat, cu execuție izolată.

Datele de conectare și secretele sunt furnizate prin configurația serviciilor și nu fac parte din fișierele publice.
